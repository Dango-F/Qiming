# Qiming 应用图标 · 栖光

依据 `Qiming-UI设计稿.md` 第 11 节绘制。制作源为矢量几何，没有使用第三方字体、图库或生成式位图素材。

## 正式资源

- `Qiming/Resources/AppIcon.icon`：Icon Composer 原生文档，已打开、检查 Default / Dark / Mono，并由 Icon Composer 保存。
- `AppIcon.icon/Assets/Lid.svg`：雾银盖沿，1024 坐标下外轮廓为 (242,418)–(782,482)，540×64，端部半径 32。
- `AppIcon.icon/Assets/Light.svg`：暖金光核，中心 (512,580)，直径 112；外围微光半径 76。净间距 42，不使用放射线或附加装饰。
- 夜墨底板是原生文档的背景填充；默认 #263542 → #15212B，深色 #293B49 → #101A24。前景共享两份 SVG。
- Xcode 主程序目标的 App Icon Name 已设为 `AppIcon`。编译器生成 `Assets.car` 与 `AppIcon.icns`，系统负责原生轮廓与表面效果。

## 可审阅与可下载文件

`Exports/Qiming-icon-review.png` 是总览：上排为 Apple 渲染器输出的默认、深色和系统着色外观，下排为尺寸核查。着色预览使用示例色相 0.58、强度 0.35；实际着色由用户系统设置决定。

`Exports/Qiming-native-Default-1024.png` 是默认外观的 1024 PNG；同目录提供 Dark、TintedLight、TintedDark 及 16、32、64、128、256、512 尺寸的原生渲染结果。

`Exports/Qiming.icns` 是额外提供的传统图标文件，包含标准 1× / 2× 尺寸。其 16 / 32 像素条目使用光学校正版：移除微光与窄边高光，按像素网格对齐，确保盖沿与光核之间至少有一整行底色。此 ICNS 是独立交付文件，未覆盖 Xcode 为 `.icon` 自动生成的兼容 ICNS。

`Qiming-*-master-1024.png` 是完整方形制作稿；`Qiming-*-preview-1024.png` 是直接绘制的轮廓研究图。这些制作稿、光学校正 PNG 与评审图都不放入应用包。正式大图与系统外观以 `Qiming-native-*` 为准。

## 同源菜单栏图形

菜单栏和面板品牌图形已改为相同的圆端盖沿与分离光核。跟随系统使用空心光核，合盖熄屏使用实心光核，始终常亮附加单色光弧；模板图像跟随系统明暗，不依赖金色区分状态。

## 再生成与检查

```sh
python3 Scripts/generate_icon_source.py
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift Scripts/draw_app_icon.swift "$PWD"
./Scripts/export_icon_previews.sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift Scripts/draw_icon_review.swift
./Scripts/build.sh Release
python3 Scripts/measure_size.py
```

已检查分层文档、默认 / 深色 / 单色外观、系统着色导出、16–1024 尺寸预览及原生资源编译。不同壁纸下的 Dock / Finder / 系统切换器完整实景矩阵尚未逐项验收；应用为菜单栏常驻程序，默认不显示 Dock 图标。

参考：[Apple Icon Composer](https://developer.apple.com/icon-composer/)、[Apple 原生图标制作说明](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer)。
