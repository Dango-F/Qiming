# 栖羽含光

姿态来自收拢的曲线。两片不对称曲面围绕同一道 S 形走势展开，外翼舒展，内翼回旋；用连续的转折表达栖息，让负空间保留呼吸。主体略高于中心，四周留白，轮廓的准确承担第一层识别。

珍珠银与香槟金形成安静的冷暖关系。曲面的体积由沿翼面展开的柔和明暗塑造，亮部保留颜色，暗部维持通透；以细致的边缘处理和克制的反差呈现温润质感。工艺感应体现在曲率与光学平衡的反复校准中。

光存在于内翼的弯折之间。暖光沿表面流动，既不脱离曲面，也不冲淡翼间的夜色。夜墨底板承托整体，不增加风景、纹理与装饰，让收拢的姿态和内在的延续自然成立。

同一母形跨越彩色与单色。大尺寸保留细腻体积，小尺寸让轮廓和留隙优先；精心校准线宽与内翼位置，避免在压缩后合并。空心、半实与全实共享路径，静态填充量传递活动程度。

制作与呈现都保持克制。曲面由可编辑的贝塞尔几何与矢量明暗构成，原生图标流程处理底板轮廓；参考图与评审稿留在开发资料中。最终完成度来自准确的形状和光感，而非增加图形与运行时效果。
