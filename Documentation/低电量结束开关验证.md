# 低电量结束开关验证

日期：2026-11-05。

- 保护页在「低于此电量时结束」前增加复选框，默认不勾选。关闭时阈值选择框禁用，辅助组件不依据电池电量或电量读数缺失结束会话；供电识别、断电暂停、定时和温度保护仍按各自设置执行。
- 勾选后启用阈值选择框，并在电池供电且电量达到或低于阈值时结束会话。接通外接电源时不因电量较低而结束。
- 新增 `ProtectionPolicy.endOnLowBattery`，默认为 false；兼容读取旧偏好，新增开关关闭，同时保留原阈值、允许电池运行、断电暂停、来电恢复和提醒间隔。
- 沿用保护页现有规则，电源与电量设置在下次会话生效。
