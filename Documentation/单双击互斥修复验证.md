# 单击与双击互斥修复

日期：2026-11-05。

## 原因与行为

上一版在第一次按下时立即执行主面板开关，第二次按下再识别双击，导致一次双击也执行了第一下的单击动作。

最终改为：

- 单击等待 macOS 的 `NSEvent.doubleClickInterval`，外加 20 毫秒事件调度余量后确认执行。
- 同一点击序列的第二下到达时取消待执行的单击，仅打开小菜单。间隔落在系统双击时间内的两下会被系统视为双击，无法同时推断为两个独立单击。
- 右键即时执行原会话操作，并取消待执行的左键单击。
- 等待期间点击别处、在应用内按 Esc、打开设置、重新显示面板或退出时取消待办，避免稍后重新弹出。
- 在按下时记录打开／关闭意图，保留已有失焦顺序修复；若前一个独立单击因主线程忙碌尚未执行，新一轮独立单击会先完成上一轮，再记录新的开关意图。
- 单击等待仅存在于点击后，不增加常驻轮询。

## 验证

- 生产 `MenuBarClickHandler` 配合构造的 NSEvent 验证：单击确认前不改变面板；展开和收起状态中的双击均不执行单击；两次独立单击分别开关；第三次连续点击不再展开；右键不等待；取消的单击不会延迟出现。
- 覆盖第一下尚未执行时到达新一轮独立单击的顺序与意图，最终状态保持正确。
- 完整面板回归 96 组切换、40 组玻璃边缘检查通过，0 失败。日志 `/tmp/qiming-click-exclusive-final-panel.log`。
- Debug、Release 构建成功。正式版已原位更新，收到正常辅助组件回执。
- 实际界面确认组件已连接、错误为无；最终恢复更新前的「跟随系统」，自有常亮断言未持有，SleepDisabled 未启用。
- 本轮状态栏物理鼠标双击未由界面工具直接操作，点击互斥验证范围为原生事件构造与面板集成检查。

- dist/Latest：DMG 3,439,093 字节，ZIP 2,865,413 字节，校验和通过。仅保留固定正式版和默认 Xcode 开发版。
