# 左键双击小菜单与版本简化

日期：2026-11-05。

- 从 `Backups/2026-11-03-menu-interaction-before/Source.tar.gz` 核对原小菜单，恢复显示主面板、设置、立即熄屏、结束会话、退出五项操作，并使用原生 NSMenu。
- 左键单击保持即时展开／收起；双击第二次按下时立即收起主面板，显示小菜单。没有为了识别双击而延迟单击响应。
- 显式允许状态栏按钮接收多次点击；第三次连续点击不重新展开面板。右键仍独立用于会话启停，不打开小菜单。
- 小菜单弹出前取消待显示任务，并立即结束正在打开或关闭的主面板显示，防止残留淡出窗口与菜单叠在一起。
- 无会话时结束会话项禁用；后台操作进行中时熄屏、结束和退出项禁用，设置和显示主面板可用。
- 通用页版本只读取 CFBundleShortVersionString，当前显示 0.1.0；安装包发布说明也去掉括号构建号。底层 CFBundleVersion 元数据保留。

验证：

1. 生产点击分类器使用构造的 NSEvent 做交互回归：单击展开／收起，双击打开菜单请求并隐藏正在打开／关闭的主面板，连续第三次点击不会重新展开，右键不混入菜单动作，模拟会话未被左键或双击改变。
2. 96 组面板切换、40 组玻璃边缘及既有动画／失焦顺序检查通过，0 失败。本轮没有重新进行物理熄屏或完整核心保护测试。
3. Debug、Release 构建成功。正式版已原位更新，取得正常 XPC 状态回执，策略 2 不限时会话恢复。
4. 正式版设置界面实际核对版本显示为 0.1.0，左右对齐，未显示构建号。
5. 界面工具未直接操作系统顶部状态栏图标进行物理双击，本轮双击覆盖为原生事件构造的路由和面板集成回归。
6. UI 设计稿、产品功能文档、使用手册及安装包发布说明同步更新。
7. dist/Latest 校验和通过：DMG 3,432,640 字节，ZIP 2,859,905 字节。系统索引仅保留固定正式版和 Xcode 开发版。

同日后续修复：用户反馈即时单击与双击动作叠加，最终改为等待系统双击判定，双击取消待执行单击。上文「单击保持即时」是上一版历史行为，当前实现及包体见「单双击互斥修复验证.md」。


> 后续变更（2026-11-05）：按用户要求删除小菜单与双击操作，恢复左键即时展开／收起。本文记录为历史验证，当前交互见《恢复单击交互验证》。
